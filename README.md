# ಹಿಂದಿ ಅಕ್ಷರ ಟ್ರ್ಯಾಕರ್

ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಈ ಫೈಲುಗಳಿವೆ:
- `index.html` — ಮುಖ್ಯ ಆ್ಯಪ್
- `manifest.json` — ಮೊಬೈಲ್ ಆ್ಯಪ್ ಮಾಹಿತಿ (ಹೆಸರು, ಐಕಾನ್)
- `icon-192.png`, `icon-512.png` — ಆ್ಯಪ್ ಐಕಾನ್
- `service-worker.js` — ಆಫ್‌ಲೈನ್‌ನಲ್ಲೂ ಕೆಲಸ ಮಾಡಲು

## GitHub ಮೂಲಕ ಅಪಲೋಡ್ ಮಾಡುವುದು ಹೇಗೆ (ಒಂದೊಂದೇ ಹಂತ)

1. **github.com** ಗೆ ಹೋಗಿ, ಖಾತೆ ಇಲ್ಲದಿದ್ದರೆ ಉಚಿತವಾಗಿ ಸೈನ್‌ಅಪ್ ಮಾಡಿ.
2. ಬಲಭಾಗದ ಮೇಲ್ಗಡೆ **+** ಬಟನ್ ಒತ್ತಿ → **New repository** ಆಯ್ಕೆಮಾಡಿ.
3. Repository ಹೆಸರು ಕೊಡಿ, ಉದಾ: `hindi-akshara-tracker` → **Public** ಆಯ್ಕೆಮಾಡಿ → **Create repository** ಒತ್ತಿ.
4. ಹೊಸ repository ಪೇಜ್‌ನಲ್ಲಿ **"uploading an existing file"** ಎಂಬ ಲಿಂಕ್ ಕ್ಲಿಕ್ ಮಾಡಿ.
5. ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿರುವ ಎಲ್ಲಾ 5 ಫೈಲುಗಳನ್ನು (index.html, manifest.json, icon-192.png, icon-512.png, service-worker.js) ಡ್ರ್ಯಾಗ್ ಮಾಡಿ ಅಥವಾ ಆಯ್ಕೆಮಾಡಿ ಅಪಲೋಡ್ ಮಾಡಿ.
6. ಕೆಳಗೆ **Commit changes** ಬಟನ್ ಒತ್ತಿ.
7. ಈಗ ಮೇಲಿನ **Settings** ಟ್ಯಾಬ್‌ಗೆ ಹೋಗಿ → ಎಡಬದಿಯ ಮೆನುವಿನಲ್ಲಿ **Pages** ಕ್ಲಿಕ್ ಮಾಡಿ.
8. "Build and deployment" ಅಡಿಯಲ್ಲಿ **Branch** → `main` ಆಯ್ಕೆಮಾಡಿ, ಫೋಲ್ಡರ್ `/ (root)` ಇಟ್ಟುಕೊಂಡು **Save** ಒತ್ತಿ.
9. ಸ್ವಲ್ಪ ಸಮಯದ ನಂತರ (1-2 ನಿಮಿಷ) ಅದೇ ಪೇಜ್‌ನಲ್ಲಿ ಒಂದು ಲಿಂಕ್ ಕಾಣಿಸುತ್ತದೆ, ಇದು ಹೀಗಿರುತ್ತದೆ:
   `https://<ನಿಮ್ಮ-username>.github.io/hindi-akshara-tracker/`
10. ಆ ಲಿಂಕ್ ಅನ್ನು ಮೊಬೈಲ್‌ನಲ್ಲಿ Chrome ನಲ್ಲಿ ತೆರೆಯಿರಿ.

## ಮೊಬೈಲ್‌ನಲ್ಲಿ ಆ್ಯಪ್ ರೀತಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುವುದು ಹೇಗೆ

**Android (Chrome):**
1. ಮೇಲಿನ ಲಿಂಕ್ ತೆರೆಯಿರಿ.
2. ಮೇಲೆ-ಬಲಗಡೆ ಇರುವ **⋮ (ಮೂರು ಚುಕ್ಕಿ)** ಮೆನು ಒತ್ತಿ.
3. **"Add to Home screen"** ಅಥವಾ **"Install app"** ಆಯ್ಕೆಮಾಡಿ.
4. ಈಗ ಹೋಮ್ ಸ್ಕ್ರೀನ್‌ನಲ್ಲಿ ಐಕಾನ್ ಕಾಣಿಸುತ್ತದೆ — ಅದನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿದರೆ ಪೂರ್ತಿ ಆ್ಯಪ್ ರೀತಿ ತೆರೆಯುತ್ತದೆ (browser bar ಇಲ್ಲದೆ).

**iPhone (Safari):**
1. ಮೇಲಿನ ಲಿಂಕ್ ಅನ್ನು Safari ನಲ್ಲಿ ತೆರೆಯಿರಿ.
2. ಕೆಳಗಿನ **Share (⬆️)** ಬಟನ್ ಒತ್ತಿ.
3. **"Add to Home Screen"** ಆಯ್ಕೆಮಾಡಿ.

## ಗಮನಿಸಿ
- ಡೇಟಾ (ವಿದ್ಯಾರ್ಥಿಗಳ ಪಟ್ಟಿ, ಪ್ರಗತಿ) ಆ ಮೊಬೈಲ್/ಬ್ರೌಸರ್‌ನಲ್ಲೇ ಉಳಿಯುತ್ತದೆ (localStorage). ಬೇರೆ ಫೋನ್‌ನಲ್ಲಿ ತೆರೆದರೆ ಡೇಟಾ ಪ್ರತ್ಯೇಕವಾಗಿ ಕಾಣಿಸುತ್ತದೆ.
- ಫೈಲ್‌ಗಳನ್ನು ಮತ್ತೆ ಬದಲಾಯಿಸಬೇಕಿದ್ದರೆ, GitHub repository ಯಲ್ಲಿ ಫೈಲ್ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ ಪೆನ್ಸಿಲ್ (✏️) ಐಕಾನ್ ಒತ್ತಿ ಎಡಿಟ್ ಮಾಡಬಹುದು.
